# Basis Pengetahuan Sparta

Folder ini adalah sumber utama Otak Sparta. Setiap kali ditanya, Otak Sparta mencari di sini dulu, lalu menyebut file yang dipakai sebagai sumber.

Taruh di sini:
- SOP dan alur kerja Building & Maintenance
- Standar toko per tipe (PDF, DXF)
- Daftar harga satuan dan daftar vendor (CSV lebih mudah dibaca daripada Excel)
- Matriks wewenang approval
- Contoh RAB, SPK, dan BAST yang sudah final

Format yang bisa dibaca: PDF, TXT, MD, CSV, DXF, PNG, JPG. File Excel perlu diekspor ke CSV dulu.

Beri nama file yang jelas, misalnya `standar-toko-tipe-A-2026.pdf` atau `harga-satuan-sipil-2026.csv`. Nama file ikut membantu Otak Sparta menemukan dokumen yang tepat.
